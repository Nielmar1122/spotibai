# 🎵 Spotibai — Bisaya Music Streaming

A modern full-stack music streaming prototype inspired by Spotify, focused on **Bisaya/Cebuano** songs and artists.

## Stack
- **Frontend:** HTML5, CSS3, Bootstrap 5, Vanilla JS
- **Backend:** Node.js + Express.js
- **Database:** MongoDB + Mongoose

## Setup

```bash
git clone <this-repo>
cd spotibai
npm install
cp .env.example .env
